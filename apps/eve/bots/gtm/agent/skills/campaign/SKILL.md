# Campaigns

Copy first is why campaigns fail. The order is audience, offer, channel,
then words.

Write `/workspace/gtm/campaigns/<slug>.md`:

- **Who**, from `icp.md`, narrow enough to name three real examples. "Small
  businesses" is not an audience.
- **Where they already are.** A channel they use, not one that is
  convenient to post in.
- **The offer.** What they get and what it costs them, in one sentence.
  If the offer is "look at our product", there is no campaign yet.
- **The proof**, from `proof.md`, that makes the offer believable.
- **The one action** you want. One. A page with three calls to action has
  none.
- **What working looks like**: the number, the window, and where it is
  measured. Agree it before launch or the result is whatever anyone wants
  it to be afterwards.
- **What could go wrong**: who might be annoyed, what claim is thinnest,
  what happens if it works better than expected.

## Then

Only then, the copy: `skills/founder-email` for outbound,
`skills/sequence` for a series, `skills/listing` for a store or
directory. Landing page copy is drafted here and the page itself is a
handoff to Designer and Software Engineer, never a PR of yours.

Everything stays a draft. Launch day is a person pressing a button.

## After

Read the result against the number you wrote down, from the sending
tool, with the window. Write it in the same file. A campaign whose result
was never written down teaches nothing and gets repeated.
